So sánh Agent, SOP, Skills, Plugins, Projects, Gems, GPTs

Kiến thức cập nhật 2026: OpenAI, Claude, Gemini & các nền tảng AI khác

📍 Mục tiêu: cấu trúc khái niệm, khi nào dùng, ưu/nhược điểm, mapping thực tế

🎯 Khái niệm cốt lõi

Agent = Nhân viên ảo tự xử lý task, tự quyết định, lặp lại các bước (agentic loop).

SOP = Quy trình chuẩn: từng bước, input–output, rule, kiểm soát chất lượng.

Skills = Hướng dẫn best practice (SKILL.md) + function definitions mà Agent có thể gọi.

Plugins/Tools = Kết nối AI với dịch vụ ngoài (API, DB, SaaS, MCP).

Projects = Container giải pháp hoàn chỉnh (Agent + SOP + Skills + Plugins + file + dữ liệu).

Gems (Gemini) / Custom GPT (OpenAI) = Mini-assistant cho user: vai trò, hướng dẫn, đôi khi gắn tools/file.

⚠️ Lưu ý: "Gems" là tên riêng của Google Gemini. Claude không có tính năng cùng tên — gần nhất là Custom Instructions trong Claude Project.
Tác nhân Quy trình Kỹ năng Tích hợp Giải pháp Trợ lý

🔄 Quan hệ tổng thể

  • Project = container cho 1 sản phẩm/use case hoàn chỉnh.
  • Agent bên trong Project: tự xử lý workflow, có agentic loop.
  • SOP định hướng Agent: "làm bước 1, 2, 3, khi nào dùng tool gì".
  • Skills = best practice docs (.md) + hàm/API mà Agent gọi.
  • Plugins/MCP = kết nối thực tế: Google Drive, Slack, DB, v.v.
  • Gems/Custom GPT = "giao diện" nhẹ cho người dùng cuối.
💡 Quy tắc vàng: Xây dựng từ Project → thiết kế Agent & SOP → xác định Skills & Plugins → cuối cùng đóng gói thành Gem/GPT.
Khái niệm Định nghĩa Khi nào dùng Mối liên hệ Pros Cons
Agent "Tác nhân" AI có mục tiêu, có agentic loop (tự quyết định, lặp lại, phản ánh), gọi tools, xử lý task đa bước. Cần tự động hóa quy trình dài, phức tạp: phân tích → quyết định → hành động → kiểm tra → điều chỉnh. Agent dùng Skills & Plugins; tuân theo SOP; thuộc Project hoặc export thành Gem/GPT. ✓ Linh hoạt, xử lý workflow dài, tái sử dụng được. ✗ Khó thiết kế & debug; phụ thuộc SOP chất lượng; có thể "lạc đề".
SOP Standard Operating Procedure: tài liệu quy trình chuẩn, mô tả từng bước, input–output, rule, tiêu chí thành công. Cần đảm bảo Agent làm việc nhất quán, có kiểm soát, dễ audit, tuân thủ quy định doanh nghiệp. Agent, Gem, GPT "đọc" SOP qua prompt/document; SOP mô tả khi nào dùng skill/plugin nào, theo trật tự gì. ✓ Rõ ràng, dễ review, dễ audit & training; tái sử dụng cho nhiều Agent. ✗ Viết & bảo trì tốn thời gian; quá cứng có thể làm Agent thiếu linh hoạt.
Skills Tập hợp: (1) SKILL.md = hướng dẫn best practice + (2) function definition mà AI gọi. Muốn tách hành động thành module rõ ràng: "gửi email", "truy vấn DB", "tạo file Excel", "phân tích dữ liệu". Agent/Gem/GPT gọi skills; Plugins thường cung cấp thêm skills; thuộc Project. ✓ Modular, dễ test từng phần, chia team phát triển, tái sử dụng cao. ✗ Nếu quá nhiều skill, AI khó chọn đúng; cần thiết kế interface & mô tả rõ ràng.
Plugins / MCP Plugin = lớp tích hợp (deprecated ở OpenAI, giờ là Actions); MCP = Model Context Protocol (chuẩn mới của Anthropic). Cần AI đọc/ghi dữ liệu thật: Google Drive, Slack, Jira, CRM, database, API, hệ thống nội bộ. Hiện thực thành skills mà Agent gọi; SOP quy định lúc nào dùng plugin/MCP nào trong Project. ✓ Mở rộng AI ra thế giới thực; tận dụng hạ tầng sẵn có; quyền truy cập chi tiết. ✗ Cần xử lý bảo mật, phân quyền, rate limit; sai cấu hình → rủi ro dữ liệu.
Projects Container cho 1 giải pháp AI hoàn chỉnh: gom Agent, SOP, Skills, Plugins, file, dữ liệu, setting, version. Xây dựng sản phẩm/use case hoàn chỉnh: chatbot CSKH, trợ lý nội bộ, hệ thống phân tích, tự động hóa nghiệp vụ. Bao gồm 1+ Agent, tập SOP/Skills/Plugins; có thể export thành Gem/Custom GPT cho user. ✓ Cấu trúc rõ ràng, hỗ trợ teamwork & versioning, dễ mở rộng & monitor. ✗ Có thể overkill cho tác vụ đơn giản; cần platform hỗ trợ concept project.
Gems (Gemini) "Mini-assistant" của Google Gemini: cấu hình vai trò, hướng dẫn, context, đôi khi gắn tools/files/knowledge. Tạo trợ lý chuyên biệt nhanh: code reviewer, coach viết, phân tích, pháp lý, v.v. trong hệ sinh thái Gemini/Workspace. Tương tự Custom GPT (OpenAI); Claude không có khái niệm này riêng — gần nhất là Custom Instructions trong Claude Project. ✓ Dễ tạo, không cần code, tích hợp sâu Google Workspace (Docs, Gmail, Drive). ✗ Hạn chế logic phức tạp; khó quản lý version; gắn chặt hệ sinh thái Google.
Custom GPT Custom GPT của OpenAI: prompt riêng, gắn file, tools (function calling), actions (API), phong cách riêng. Tạo "ứng dụng nhỏ" hoặc trợ lý chuyên ngành trong ChatGPT Pro/Enterprise; dễ phân phối cho user. Tương tự Gem của Claude; bên trong gọi tools/function calling; SOP viết trong prompt/docs. ✓ No-code setup, nhanh, phù hợp business user, dễ phân phối, có marketplace. ✗ Không linh hoạt bằng Agent/Project; quản lý version khó; logic dài tương đối phức tạp.

🌐 Mapping sang các nền tảng AI (2026)

🔵 OpenAI (GPT)

  • Agents: Assistants API (có tool use) hoặc custom agentic loop
  • SOP: system prompt + tài liệu đính kèm
  • Skills: function calling / tool definitions
  • Plugins: ❌ Deprecated (2024) → dùng Actions trong Custom GPT
  • Projects: ứng dụng bạn build bằng API + hạ tầng riêng
  • Custom GPT: trong giao diện ChatGPT Pro/Enterprise

💜 Claude (Anthropic)

  • Agents: build qua API + tool use + orchestration
  • SOP: system prompt + guidelines + dữ liệu ngữ cảnh
  • Skills: SKILL.md (best practice) + tool definitions
  • Plugins/Tools: tool use + MCP (chuẩn mới)
  • Projects: Claude Project = workspace + custom instructions + knowledge files + conversation history
  • Mini-assistant: ❌ không có "Gem" riêng — dùng Custom Instructions trong Project

🟢 Gemini (Google)

  • Agents: Vertex AI Agents / Google AI Studio
  • SOP: prompt, instruction set, workflows
  • Skills: function calling + Google Workspace integration
  • Plugins/Tools: tích hợp Google & API bên ngoài
  • Projects: GCP Project (Vertex AI)
  • Gems: mini-assistant tùy biến, tích hợp sâu Workspace (Docs, Gmail, Drive)
📌 MCP (Model Context Protocol): Chuẩn mới của Anthropic (2024+) cho phép kết nối an toàn, modular với các dịch vụ. Giống như "plugin" nhưng rõ ràng & bảo mật hơn. Claude + MCP = tương lai.

🎯 Chọn công cụ nào?

👤 Task đơn giản, một lần

Sử dụng Gem hoặc Custom GPT thẳng.

Ví dụ: viết email, dịch văn bản, giải thích code.

🔄 Workflow lặp lại, có rule

Xây Project + SOP, thiết kế Agent.

Ví dụ: review code, tạo ticket, gửi report hàng ngày.

🌐 Cần kết nối hệ thống

Thêm Plugins / MCP vào Project.

Ví dụ: Agent đọc Slack, update Jira, ghi Google Drive.

👥 Chia sẻ với team

Xuất Gem (Gemini), Custom GPT (OpenAI), hoặc Claude Project chia sẻ team.

Ví dụ: trợ lý pháp lý, code reviewer, content writer.

📊 Bản sản xuất / SLA

Full Project + SOP + Monitoring.

Ví dụ: CSKH bot, hệ thống phân tích tài chính, tự động hóa HR.

🛠️ Cần debug / control

Build Agent + API tuỳ chỉnh.

Ví dụ: orchestration phức, custom logic, xử lý error.
